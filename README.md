# Công ty ACL — Quản lý tồn kho

Ứng dụng quản lý tồn kho nằm trong thư mục [inventory](inventory/README.md).

Chạy trên một máy bằng Python và SQLite, hỗ trợ nhập Excel ACL, nhập/xuất hàng và báo cáo tồn theo ngày. Xem hướng dẫn cài đặt trong thư mục ứng dụng.

Kho mã nguồn không chứa dữ liệu khách hàng, giao dịch hoặc file Excel thực tế.
